The task list tells the truth: a task with an agent working on it says in progress, a request filed under done says merged instead of cancelled, every task with a worktree, branch or pull request has a row, and done tasks say how long they took again, from their pull request where nothing else recorded it. A merged task now moves to deployed once the site, APK and API deploys for its merge go green, and says so on the row while one is still running, when one failed, or when the merge had nothing to deploy.
