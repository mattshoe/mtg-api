What was wrong: The last fix only changed what happens when a deck is saved. Cracker Barrel's two rows, Aang, Swift Savior and Witch Enchanter, were saved before it and still named only the front face, so the deck page still matched them to nothing and said 2 not owned. The summary told you to re-save the deck to clear it, which was a chore that should not have been yours.
Why: The deck page counts what you own by matching each row's name against your collection, and the collection only has the full two-faced name, like Aang, Swift Savior // Aang and La, Ocean's Fury. Nothing rewrote old rows.
Fix: A one-time database migration renames any deck row named by a front face to the card's full name, and fills in its oracle id. It runs when the Worker deploys. Live, it touches exactly Cracker Barrel's two rows, which I checked before writing it. Server only, so the phone and the website both read the fixed rows.
