What was built: A second Guide tile, Rules, on the phone and the website. It opens a page with a search bar at the top. Type trample, or 702.19, and every rule that mentions it shows as its own card: the rule number as the heading, the section it sits in beside it, the text, and any examples under it. Every card starts open and a tap on its heading folds it.
Choices: The live rules. The Worker reads magic.wizards.com/en/rules for the current .txt link and hands the file over untouched, because Wizards sends no CORS header and the website could not fetch it itself. Cloudflare keeps it a day. Both apps parse and search it on the device, in shared code, so the phone and the site cannot number a rule differently. Search wants every word you type, ignores case, and a rule number finds its subrules too. If the fetch fails the page says why with a Try again button, and there is no spinner left behind.
Liberties: Only numbered rules are searched, not the glossary. An example counts as part of the rule it sits under, so searching protection finds 702.19b through its example. A very broad search shows the first 150 cards and says how many there were. A blank search shows a hint and the date the rules took effect rather than all of them.
