What was built: A task's time on Admin Settings and its details page now counts from when an agent picked it up from the queue. Time spent waiting in the queue is left out. Done tasks say how long they took from pickup to finish.
Choices: A task nothing has picked up yet, queued, pending or held, shows no time at all rather than a zero. A task cancelled before it started says nothing about how long it took.
Liberties: None. The Worker already recorded the pickup time, so only the app's counting changed.
