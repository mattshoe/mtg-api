What was built: A search bar on the Game Changers page in the Guide, on the phone and the website, under the line about the brackets. Typing narrows the 53 cards to the ones whose name has every word typed, under the same type headings, with "5 of 53 cards" above them. A name nothing has says "No game changer is called ...". Tapping a found card opens the carousel over only the found cards, in the order they are listed. Clearing the bar brings all 53 back.
Choices: Matching ignores capitals and apostrophes, so "lions eye" finds Lion's Eye Diamond, and it reads both faces of a two-faced card, so "lantern" finds Tergrid. Headings with nothing left under them are hidden.
Liberties: It searches names only, not type lines or rules text, since the request said name search. Nothing calls the network, so there is no loading or error state.
