What was built: A Tools tab in the bottom bar, phone and website, in the slot Fetch had. It opens on tiles laid out like the Users tab, one for Fetch and one for Entry, each with the icon that tool had in the bar sitting in the round spot a profile picture takes, its name, and a line on what it does. Tapping a tile opens the tool, and the Tools tab stays lit while you are in it. Fetch and Entry are no longer in the bar.
Choices: The bar is Library, Decks, Users, Tools, Guide for everybody. Entry still needs you signed in, so a signed-out visitor sees only the Fetch tile. The phone's Tools tab got its own icon, a toolbox. The website's menu is words, not icons, so its tiles carry the phone's Fetch and Entry icons and the menu just says Tools. The addresses #/fetch and #/entry still work, and so does the "e" shortcut for Entry.
Liberties: The header over Fetch and Entry now says "Fetch" or "Entry" rather than the app's name, because they are no longer tabs in the bar. There is no "‹ Tools" button over a tool, the Tools tab and back do that job.
