What was built: A Users tab in the bottom bar, phone and website. It opens on a grid of tiles, one per account, each with the profile picture (or the first letter of the name in a circle when there is no picture), the name, and how many cards and decks they have, biggest collection first. Tapping a tile opens that person's cards in the real Library page, search, filters, sort, carousel and export included, under a "‹ Users" button and "Kayla's cards".
Choices: Their Library lives under the Users tab, at #/users/<key>, so your own Library tab stays yours while you look around. The tiles are the Guide's tiles with a face added, as many across as fit, so a tablet gets a grid. The list is read with ordinary SQL over the open query endpoint, like every other page, so no Worker change and no schema change. It never reads an email address, and the intake agent's account is left out.
Liberties: The filters you set are shared between your Library and theirs, so a search carries over when you switch. Opening #/users/<key> straight from a link names the person by their key until the tiles have loaded. The website's menu is words, not icons, so only the phone got a new icon, two people side by side.
