What was wrong: The new deck wizard's name check refused a two-faced card written with both faces, "Aang, Swift Savior // Aang and La, Ocean's Fury", if nobody in the collection owned it yet. Cutting the back face off made it pass, which is what you had to do.
Why: The check asks Scryfall about any name the collection does not know, and it sent the name exactly as written. Scryfall's bulk lookup answers "not found" for every name with both faces in it, checked against the live API. Adding cards already sent the front face only, the check never did. The test stand-in for Scryfall answered full two-faced names, so no test could see it.
Fix: The check now sends the front face to Scryfall and matches the full name that comes back, so a made-up back face still fails. The test stand-in now refuses two-faced names the way Scryfall does. Server only, so the phone and the website both get it from the same check.
