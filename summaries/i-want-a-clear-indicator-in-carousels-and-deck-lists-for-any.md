What was built: A gold mark on every game changer, on the phone and the website. A deck list row shows "GC" next to the card's name. Every card carousel (decks, Library, fetch lists, the Guide) shows "Game Changer" beside the name at the top of the sheet. Screen readers hear "Game Changer" for both.
Choices: The mark is filled with the app's gold with dark text, so it stands out by lightness rather than colour alone. The row says "GC" instead of the full words so a long card name keeps its room on a phone. Which cards count comes from the same Wizards list the Guide's Game Changers page uses, matched by front face, so two-faced cards are caught too.
Liberties: The Guide's own Game Changers list does not mark its rows, since every row there is one. The Library grid is not marked, since the request named carousels and deck lists.
