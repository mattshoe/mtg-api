What was built: A bin on each person's page in Admin Settings, phone and website. Tapping it asks "Delete Kayla M's account? Their cards, decks, saved lists and sign-in go with it, for good. Nobody else's are touched." with Delete and Keep. Delete calls a new Worker route, POST /admin/users/delete, which removes that account and everything it owns in one D1 transaction: cards and every row hanging off them (faces, colours, types, keywords, finishes, games, promo types, frame effects, tags, search rows), decks with their lists and notes, sessions, Google sign-ins, push devices, saved Fetch lists, then the account. Every statement is scoped by the one numeric id the key resolves to, never a name or pattern. The person leaves the list and the Users tab, and the page goes back to the list. If the Worker refuses or the connection drops, the spinner stops, the page says why, and the bin works again.
Choices: The safety test dumps every row of every table before and after a delete and holds every row that is not the deleted account's to be byte for byte the same. Both Matt and Kayla get one of everything (a device, saved lists, a session, a sign-in, a task, a deck note, tags, a shared printing) so a WHERE that matched on the wrong thing has something to take. A ratchet fails if anybody adds a table pointing at users, cards or decks without teaching the delete about it. Refusals (user, agent, nobody signed in, your own account, unknown key, missing or non-string key, % and quote patterns) are each checked to change nothing at all. A mutation that deleted every device instead of Kayla's turned the safety test red.
Liberties: You cannot delete your own account from Admin Settings, the Worker answers 409, because the session doing it would go with it and the last admin could lock everybody out. Another admin can. A task the deleted account sent stays on the task board with its sender blanked, since it is a task about the app, not their data. Prices, card aliases and Tagger data belong to no one and are left alone; the nightly sweep already removes anything no card uses.
