What was built: An x at the right end of every single-line text box on the phone and the website. It shows once the box has something in it and clearing it empties the box the same way backspacing to nothing would, so a search or filter goes back to showing everything. On the website the cursor stays in the box afterwards.
Choices: Covers the Guide, rules and Game Changers searches, the Admin account search, Find a card, card name autocomplete, deck name and commander boxes, the new deck name, the fetch list title, the deck tweak card finder, and every filter text, number, range and tag box. The x is hidden while the box is empty. Chrome adds its own x to search boxes on the website, that one is hidden so there is only one.
Liberties: The quantity box beside the minus and plus on a deck tweak has no x. Emptying it does nothing there, the count stays, so an x would be a button that does nothing. Multi-line boxes like decklists and task details have none either, the request said single line.
