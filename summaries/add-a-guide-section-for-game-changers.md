What was built: A Game Changers tile in the Guide, on the phone and the website, after Rules. It opens a list of all 53 Game Changers drawn like a deck page: a section per type (Creatures, Planeswalkers, Instants, Sorceries, Artifacts, Enchantments, Lands) with its count, and a row per card with its art, name and type line. Tapping a row opens the same card carousel decks and the Library use, on that card, and you can swipe through the whole list in page order. A line over the list says what Game Changers are and how many each bracket allows.
Choices: The list is written into the shared code, taken from Scryfall's is:gamechanger on 2026-10-14, with one printing each for the art. The collection only has the ones somebody owns, so it could not be the source. Nothing on the page calls the network apart from the card images, so there is no loading or error state to get stuck in. The carousel shows the card's type, colours, rarity and EDHREC rank, and no count, owned number or deck buttons, because nobody holds these cards, they are a reference.
Liberties: When Wizards change the list it has to be changed here by hand. The list does not say which ones you own. The carousel's details button opens the card page by name, the same as a deck card nobody owns.
