What was built: A Cancel task button on every live task's page, on the phone and the website. It asks first. Yes writes cancelled to the task, and the laptop's next intake tick, within a minute, kills the agent working on it along with everything that agent started, and marks the request file cancelled so it is never built again.
Choices: The kill happens on the laptop, because that is where the agents run, and it reads the cancel off the task's row in D1 like every other status. It runs on every tick, even with intake switched off, since agents can still be running then. When a killed agent exits, the dispatcher records cancelled rather than paused. Only a pull request that already merged outranks a cancel.
Liberties: Pull requests, branches and the worktree are left exactly as they are, as asked. A done task has no Cancel button, because there is nothing left to stop. Within a minute rather than instantly, because the laptop checks once a minute and the app cannot reach it directly.
